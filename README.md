# LostLink

LostLink is a college-focused Lost & Found platform that helps students report, search, and claim lost or found items.

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- React

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate

### Database
- PostgreSQL
